## Gates

### 0 · Spark
- [ ] 3+ ideas compared (Feasibility, Innovation, Audience fit)
- [ ] Chosen idea passes the 5 market filters, one line of evidence each
- [ ] "Why me" written

### 1 · Concept
- [ ] Pillars and player fantasy written (PROJECT.md)
- [ ] Core loop at 3 scales (seconds, session, whole game)
- [ ] 3+ comparable games with price, reviews, rough sales; 2+ healthy for a similar team size
- [ ] Genre-first hook; 5 strangers can name the genre and what they would do
- [ ] Business targets: platform, price range, length, time budget, money budget

### 2 · Find the Fun
- [ ] Core loop playable end to end in one sitting
- [ ] Developer played 10+ times, self-play log written
- [ ] Riskiest design question answered
- [ ] Core loop stable for the last 1–2 iterations

### 3 · Validate
- [ ] Go/no-go criteria written and dated before testing
- [ ] 5+ blind testers (not friends/family) played
- [ ] Results vs criteria; decision recorded (Go / Iterate / Pivot / Kill)

### 4 · Pre-production
- [ ] Art target image, method and cost per asset
- [ ] Engine skeleton builds on target platform; riskiest tech question answered
- [ ] Specs for every system in the vertical slice
- [ ] Production plan v1 fits the time budget (or scope cut)
- [ ] Vertical slice scope written and small
- [ ] Business items due (name/trademark, store account, tax, licenses)

### 5 · Vertical Slice
- [ ] Slice plays 15–30 min without crashes at final quality
- [ ] Stranger playtest on the slice meets the stage-3 criteria
- [ ] Real unit costs measured; plan v2 fits (or scope cut)
- [ ] Store page live; capsule and trailer show the core verb in 5 seconds
- [ ] Publisher decision made

### 6 · Production → Alpha
- [ ] Feature lock: every planned feature implemented
- [ ] Playable start to finish (placeholders allowed)
- [ ] Plan re-estimated each milestone; cuts recorded

### 7 · Alpha → Beta
- [ ] Content lock, no placeholders on the critical path
- [ ] No known crash or progression blocker
- [ ] An external tester finished the whole game
- [ ] Demo build chosen and tested (if a festival is planned)

### 8 · Beta → Launch
- [ ] Release candidate: no S1/S2 bugs, minimum spec OK, saves compatible
- [ ] Store page complete, date announced, price set
- [ ] Wishlist/audience target reached, or date moved deliberately
- [ ] Launch checklist done

### 9 · Launch
- [ ] Critical post-launch bugs fixed
- [ ] Postmortem written
- [ ] Next decision: updates, port, sequel or move on
