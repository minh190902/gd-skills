# Store page checklist

## Capsule and art
- [ ] Main capsule readable at thumbnail size (genre and mood visible, title legible)
- [ ] Art style on the capsule matches the actual game
- [ ] Logo/title treatment consistent across capsule sizes

## Trailer
- [ ] Core gameplay verb visible within the first few seconds; no long logos or lore intro
- [ ] 30–90 seconds for the main trailer
- [ ] Ends with the call to action (wishlist) and the release window

## Text
- [ ] Short description: genre first, then what the player does, then the twist
- [ ] Long description: scannable sections with GIFs of key features; each section = one player activity
- [ ] No comparison claims to other games that the game cannot keep

## Screenshots
- [ ] First 4 screenshots show gameplay, not menus or lore art
- [ ] Each screenshot shows a different activity or moment

## Metadata
- [ ] Tags match the comparable games' audiences (genre tags first)
- [ ] Supported languages accurate; system requirements filled
- [ ] Content survey (mature content, AI-generated content) completed honestly

## Before promoting
- [ ] Hook test passed with strangers (§B in gd-go-to-market)
- [ ] Links: Discord/mailing list/social on the page
- [ ] Press kit page ready
