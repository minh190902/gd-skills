# Launch checklist

## 6–8 weeks before
- [ ] Release date announced; date avoids major same-genre releases and store-wide sales
- [ ] Price, launch discount and regional pricing set
- [ ] Release candidate build tested on minimum spec; save compatibility checked
- [ ] Press kit complete; press and creator list updated
- [ ] Launch trailer in production

## 2–4 weeks before
- [ ] Store page final review submitted; build review submitted
- [ ] Creator/press keys sent with embargo date
- [ ] Community announcement schedule written
- [ ] Achievements, cloud saves, controller support (if any) verified

## Launch day
- [ ] Release at a time the developer can be online for the following hours
- [ ] Announcement posted on every channel; launch trailer live
- [ ] Crash reporting and feedback channel monitored

## Launch week
- [ ] Daily review reading and polite replies; no arguing
- [ ] Hotfix for blockers within days; changelog posted
- [ ] Track sales, refunds, wishlist conversion; note what drove spikes

## After 1 month
- [ ] Postmortem written (what worked, what to repeat, what to avoid) and recorded in DECISIONS.md
- [ ] Decide: updates, content, ports, next project
